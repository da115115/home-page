\section{Sources des programmes}

L'ensemble de ces programmes représente environ 3000 lignes de code Java,
que nous avons entièrement créées. Ainsi, il s'en dégage une certaine
homogénéité qui devrait permettre une utilisation future plus aisée. Dès le
départ, ces programmes ont été écrits avec l'idée qu'ils puissent être
utilisés par d'autres applications. Pour toutes ces réalisations, nous
nous sommes basés sur l'excellent livre: {\it Java in a Nutshell, 2nd
  edition}, de David Flannagan aux Editions O'Reilley \& Associates.

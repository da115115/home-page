3.1.10 User-level security policy

Ultimately, computer security is the user's responsibility. Each user must be alert to possible breaches in security and adhere to the security regulations that have been established within their company. The security practices listed in Appendix 1 are not inclusive, but rather designed to remind them and raise their awareness towards securing their information resources.

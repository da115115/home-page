Transaction Processing with Java and CORBA

Rapport de Thèse Professionnelle — Systèmes répartis et intergiciels

Auteurs : Denis Arnaud (Institut Eurécom / Sema Group Telecom)

Encadrants : Jean-Michel Rocher (Sema Group Telecom), Refik Molva (Institut Eurécom).

Présentation / Contexte

Rapport de thèse professionnelle portant sur le traitement transactionnel distribué, les architectures logicielles n-tiers (WebTier, Business Tier), les moniteurs transactionnels (TP Monitors), l'intégration de Java avec l'intergiciel CORBA (Object Request Broker) et les standards OTS (Object Transaction Service).
